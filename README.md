## Информация о Спрайтах
- **Apple** — отображает элементы массива (клоны).
- **Star** — показывает место пропущенного числа.
- **Cat** — проходит по массиву и считает сумму.

## Запуск
Нажать 🟢. Массив заполняется примером `[3, 0, 1, 5, 2]`,  
пропущенное число — **4**.
